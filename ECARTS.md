# Écarts relevés — Projet 6 (Zero Trust)

Ce fichier liste les incohérences et erreurs techniques trouvées en confrontant le rapport de conception (référence), les diagrammes `conception/uml/*.puml`, la documentation officielle des logiciels et le guide de réalisation.

**Règle :** aucun de ces écarts n'est corrigé dans le rapport. Chaque ligne propose une correction ; le groupe décide. Le guide de réalisation applique la proposition seulement quand c'est indiqué « appliqué dans le guide », et le signale à l'endroit concerné.

Gravité : **haute** = bloque le laboratoire ou fausse un indicateur ; **moyenne** = risque d'erreur ou de question en soutenance ; **basse** = cosmétique ou documentaire.

Versions de référence vérifiées le 12 novembre 2026 : Proxmox VE 9.2, OPNsense 26.7 (Suricata 8.0 intégré), Debian 13 « trixie », Docker Engine 29, Kali Linux 2026.3.
